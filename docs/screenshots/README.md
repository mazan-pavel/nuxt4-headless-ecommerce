# Скриншоты консультанта

Положите PNG в эту папку с именами ниже. В README ссылки уже заготовлены; пока файлов нет — в таблице там стоят TODO.

| файл | кадр |
|------|------|
| `01-launcher.png` | Плавающая кнопка на каталоге |
| `02-empty-suggestions.png` | Пустой чат со стартовыми подсказками |
| `03-gift-cards.png` | Карточки по запросу «подарок до $30» |
| `04-shipping-return.png` | Ответ про доставку и возврат |
| `05-cart-add.png` | Добавление в корзину из чата |
| `06-mobile.png` | Панель на узком экране |
| `07-dark.png` | Тёмная тема |

Рекомендации: десктоп ~1280×720, мобильный ~390×844, без личных данных в `.env`.
